# blud studio

Локальная студия для генерации TikTok-каруселей в стиле «гайдов» (как у ixepill): тёмный
интерфейс, подключение своей LLM, 9 готовых стилей, редактор каждого слайда и экспорт в PNG.

- **Своя модель.** Подключи локальную LLM (Ollama, LM Studio, llama.cpp, vLLM) или любой
  OpenAI-совместимый API (OpenRouter, Groq, DeepSeek…), а также Anthropic. Попроси её сгенерировать
  что угодно — текст слайдов она придумает сама.
- **Стиль как у ixepill.** Три стиля повторяют их слайды (светлая сетка, тёмный неон, глянцевая
  обложка) плюс 5 новых: Noir, Blueprint, VHS, Ascend Gold, Soft Paper, Terminal.
- **Настройка стиля.** Любой стиль правится ползунками (цвета, шрифты, текстуры) или прямо
  текстом: «сделай фон фиолетовым, заголовок с неоном» — это применит подключённая LLM.
- **Готовые вояки.** В комплекте ~90 отобранных вояков; картинки можно и загружать свои.

## Запуск

```bash
pip install -r requirements.txt
python run.py                 # откроется http://127.0.0.1:8000
```

Открой вкладку **Подключение** и укажи свою модель (есть пресеты в один клик). Для локальных
серверов ключ не нужен. Нажми «Проверить связь».

## Как пользоваться

1. **Создать** — опиши карусель, выбери стиль, нажми «Сгенерировать». Каждый слайд можно
   открыть и отредактировать вручную: текст, тип слайда, картинки (поменять вояка, загрузить своё).
   «Изменить текст каруселью» отдаёт правку целиком модели («добавь слайд с выводом»).
2. **Стили** — галерея из 9 стилей; справа — редактор: цвета, шрифты, текстуры, правка через LLM,
   сохранение как новый стиль. Встроенный стиль можно сбросить к исходному.
3. **Проекты** — все сохранённые карусели.
4. **Экспорт** — «Экспорт PNG (zip)» собирает все слайды 1080×1440 и `caption.txt` в один архив.

## Что где лежит

```
run.py                  запуск
app/
  server.py             FastAPI: генерация, правка, стили, проекты, загрузка картинок
  llm.py                бэкенды LLM (OpenAI-совместимый и Anthropic)
  prompts.py            системные промпты (генерация / правка / стиль)
  store.py              хранение в файлах
  styles/*.json         9 встроенных стилей
  static/               интерфейс (index.html, app.js, редактор слайдов и стилей, рендер, экспорт)
    slide.css/js        движок рендера слайда (один шаблон, стили меняют CSS-переменные)
    fonts/              8 шрифтов с кириллицей (локально)
library/wojaks/         отобранные вояки (в комплекте)
userdata/               твои настройки, проекты, стили, загрузки — создаётся при работе
tools/                  fetch_wojaks.py (полная библиотека вояков), scrape_tiktok.py
```

Приватность: наружу уходят только запросы к той модели, которую ты указал. Всё остальное — локально.

## Безопасность контента

В промпт генерации зашит запрет на инструкции по приёму препаратов, инъекциям и самодельным
медицинским процедурам — для таких тем модель делает слайды о рисках, а не руководство. Это
сделано осознанно: формат смотрят подростки.
