# Фронтовой Гамбит (Front Gambit)

Военные FPS-шахматы для Android: 3D-доска с видом сверху, а каждая атака превращается
в схватку в реальном времени, где вы лично управляете фигурой и стреляете за неё.

**Готовый APK:** [`FrontGambit.apk`](FrontGambit.apk) (Android 7.0+, альбомная ориентация).

## Что есть в игре

- **Шахматы + FPS.** Фигуры ходят по шахматным правилам. При взятии начинается бой на арене
  (twin-stick: левый стик — движение, правый — прицел/огонь, кнопка — спецспособность).
  Соседние союзные фигуры приходят на помощь бойцами под управлением ИИ.
- **Юниты со своими способностями** (на доске и в бою):
  - ♟ Пехотинец — автомат, граната; *Окопаться*.
  - ♞ Спецназ — ПП, рывок; *Диверсионный рейд* (оглушение).
  - ♝ Снайпер — винтовка, артналёт; *Артудар* по площади.
  - ♜ Танк — пулемёт, пушка, давит укрытия; *Огонь с места*.
  - ♛ Вертолёт — летает над стенами, миниган и НУРСы; *Ракетный залп*.
  - ♚ Генерал — штаб в бункере; *Мобилизация*, охрана в бою. Уничтожен генерал — поражение.
- **FPV-дроны** — полёт камикадзе-дрона от первого лица над полем боя, РЭБ создаёт помехи.
- **Экономика и логистика** — заводы, доход от территории, железные дороги (переброска юнитов
  по путям и снабжение), отрезанные от тыла юниты не лечатся и слабее.
- **Линия фронта** — территория считается по близости войск, фронт подсвечен на доске.
- **Блицкриг** (+2 действия), **авиаудары**, **мины**, **диверсии** (подрыв заводов и ж/д),
  подкрепления и новые танки с завода.
- **Режимы:** против ИИ (3 уровня), вдвоём на одном устройстве, **онлайн** по коду комнаты.
- Лимит 60 ходов — затем перемирие и победа по очкам (территория, армия, заводы).

## Мультиплеер

Онлайн работает через WebRTC (peer-to-peer). Для поиска соперника используется бесплатный
публичный сервер-брокер PeerJS (`0.peerjs.com`) и бесплатные STUN/TURN-серверы. Один игрок
создаёт комнату и сообщает 5-символьный код, второй вводит его. Создатель комнаты — хост:
его устройство считает всю симуляцию, второе получает состояние и отправляет ввод.

## Сборка

Нужны Node.js, JDK 17+ и Android SDK (`platforms;android-34`, `build-tools;35.0.0`).

```bash
npm install
ANDROID_HOME=/path/to/sdk ./build.sh   # -> FrontGambit.apk
```

Сборка идёт без Gradle: esbuild собирает игру (three.js + PeerJS) в один файл,
`aapt2`/`javac`/`d8`/`apksigner` упаковывают её в APK с WebView-обёрткой
(`android/java/.../MainActivity.java`), которая отдаёт ассеты с виртуального https-адреса.

Для разработки достаточно открыть `web/dist/index.html` в браузере после
`npm run bundle && cp web/index.html web/style.css web/dist/` (на ПК: WASD + мышь, Пробел — способность).

Самопроверка правил и ИИ (20 партий ИИ против ИИ): `node test/selftest.mjs`.

## Структура

- `web/src/rules.js` — правила, экономика, территория, снабжение, способности.
- `web/src/ai.js` — ИИ-командующий.
- `web/src/duel.js` / `duelView.js` — симуляция и 3D-вид боёв.
- `web/src/drone.js` — FPV-дрон.
- `web/src/boardView.js`, `models.js`, `fx.js` — 3D-доска, процедурные модели, эффекты.
- `web/src/net.js` — онлайн через PeerJS; `main.js` — меню, режимы, игровой цикл.
